One word for your Wi-Fi: **Gaslighting** — it swears it is connected, full bars and all, while nothing loads. A small Python program that scores a shortlist of candidate words against the judge's brief (on-subject first, then funny, then true, then fresh, then instantly readable) and writes the winning word to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
